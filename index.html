What is this?

A small community SMP with an actual memory.

We are not a giant Minecraft network, and that is the point. Players recognize one another, build towns, run shops, make questionable decisions, and gradually turn the survival world into a place with history.

“Someone is probably starting political drama in The End.”

A different kind of survival server

Made for builders, traders, and players who want somewhere to settle.

Cozy Crafters keeps the familiar rhythm of Minecraft survival while adding thoughtful reasons to care about the world around you. Claim a home, help a town grow, open a player shop, work toward server goals, or simply explore what the community has built.

The server is welcoming to players who prefer cooperation, creativity, and long-term projects over constant resets or pay-to-win competition. Custom menus and quality-of-life features make everyday play smoother without replacing the survival experience.

Cozy Crafters server FAQ

Everything you need to know before joining the world.

Is Cozy Crafters a Java or Bedrock server?

Cozy Crafters is a Java Edition Minecraft server. Connect using play.cozycrafters.net.

What kind of Minecraft server is it?

It is a community survival SMP focused on building, player towns, trading, shops, land claims, events, and long-term server history.

Is the server pay-to-win?

No. Supporter ranks help fund the server, but they do not replace fair survival progression with paid power.

How do I join?

Open Minecraft: Java Edition, choose Multiplayer, add the server address, and connect. Our step-by-step joining guide has the full instructions.
