Three easy steps

How to add the server

  1. 1

    Open Multiplayer

    Launch Minecraft: Java Edition, choose Multiplayer, then select Add Server.

  2. 2

    Enter the address

    Name it “Cozy Crafters” and enter play.cozycrafters.net in the Server Address field.

  3. 3

    Join the world

    Save the server, select Cozy Crafters in your server list, and press Join Server.

Before you connect

What you need

  • A Minecraft: Java Edition account
  • A compatible 26.2 game version
  • The server address: play.cozycrafters.net

You do not need to buy a supporter rank or download a custom modpack to start playing.

Once you arrive

Start at your own pace

Explore the spawn area, choose somewhere to settle, protect your build with a claim, and meet players in chat. You can build independently or become part of a player town.

The Discord is the best place to see announcements, ask questions, and learn what the community is currently working on.
